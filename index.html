02 / Kamera einrichten

Die richtigen
Einstellungen.

Klicke links auf einen Punkt. Die Menübezeichnungen können je nach Sony-Modell etwas abweichen.

Schritt 01 · Menü → Aufnahme

Video-Modus einstellen.

Drehe das Modusrad auf Film. Drücke MENU → Aufnahme → Dateiformat.

DateiformatXAVC S HD
Aufnahmeeinstellung50p 50M oder 25p 50M
Für 4K-Capture-CardXAVC S 4K · 25p
Schritt 02 · Menü → Fokus

Gesicht immer scharf.

Drücke MENU → Fokus → Fokusmodus. Wähle AF-C und aktiviere Gesichts-/Augen-AF.

FokusmodusAF-C
MotiverkennungMensch
Gesicht/Auge PrioritätEin
Schritt 03 · Menü → Belichtung

Natürlich statt flackernd.

Stelle das Modusrad auf M. Zuerst Verschlusszeit, danach Blende und zuletzt ISO einstellen.

BelichtungsmodusM · Manuell
Verschlusszeit bei 25p / 50p1/50 s / 1/100 s
Blendef/2.8–f/4
ISO100–800, nicht automatisch
Weißabgleich5.600 K bei Tageslicht
Bei warmem Kunstlicht funktionieren meistens 3.200–4.000 K besser.
Schritt 04 · Menü → Setup

Clean HDMI aktivieren.

Drücke MENU → Setup → HDMI-Einstellungen. Danach die Kamera mit der Capture Card verbinden.
